# 🛍️ Retail Sales Analytics & Performance Dashboard

## 📌 Project Overview

**Retail Sales Analytics & Performance Dashboard** is an Excel-based data analytics project designed to analyze retail sales transactions and generate meaningful business insights.

The project focuses on transforming raw retail sales data into a structured and understandable analysis using **Microsoft Excel, data cleaning, PivotTables, KPI calculations, and data visualization**.

---

## 🎯 Objectives

The main objectives of this project are:

* Clean and prepare the retail sales dataset.
* Analyze overall sales performance.
* Calculate important business KPIs.
* Identify sales trends and transaction patterns.
* Analyze product and category performance where the dataset supports it.
* Create meaningful visualizations.
* Generate actionable business insights.
* Support data-driven decision-making.

---

## 📂 Dataset

**Dataset:** `Retail_Sales.xlsx`

The dataset contains retail sales transaction information used for analysis and reporting.

Typical analysis areas include:

* Transaction information
* Sales values
* Product/category information
* Dates and time periods
* Quantity-related information
* Customer-related information, where available

> The exact analysis is based on the columns and information available in the source dataset.

## 🧹 Data Cleaning

The dataset is prepared before performing the analysis.

The cleaning process includes:

* Checking missing values
* Identifying duplicate records
* Checking incorrect data types
* Standardizing data formats
* Validating numerical values
* Formatting date fields
* Checking inconsistent entries
* Preparing the dataset for analysis

* **Average Sales**

## 📈 Analysis

### Sales Performance Analysis

The project analyzes sales performance across available time periods and identifies changes and trends in sales.

### Product Analysis

Products can be analyzed based on available sales and quantity information to identify high-performing and low-performing products.

### Category Analysis

Category-level analysis helps understand the contribution of different product categories to overall sales.

### Transaction Analysis

Transaction-level analysis is used to understand sales volume, transaction values, and overall purchasing patterns.
